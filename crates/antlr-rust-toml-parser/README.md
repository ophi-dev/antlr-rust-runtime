# antlr-rust-toml-parser

Checked-in TOML lexer/parser and decoded syntax facade used by
`antlr-rust-codegen` semantic pattern files. This lockstep implementation crate
is not a standalone public TOML API.

The recognizers are generated by this project's own `antlr4-rust-gen` from the
pinned Apache-2.0 grammar under `third_party/toml-grammar/`.
